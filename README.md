\# Mood Map Android App



Mood Map is a simple Android mood tracking application built for my MAC220 Android Development final project.



\## Features



\- User login and registration

\- Home dashboard

\- Daily mood tracking

\- Mood selection with emojis

\- Mood intensity slider

\- Optional mood notes

\- Mood history screen

\- Mood statistics

\- Mood streak tracking

\- Dark mode toggle

\- Clean mobile-friendly UI



\## Tech Stack



\- Kotlin

\- Android Studio

\- XML Layouts

\- SharedPreferences

\- Gradle



\## Purpose



The purpose of this app is to help users track their daily emotions, review mood history, and better understand mood patterns over time.
